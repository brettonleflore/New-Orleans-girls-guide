# Girls Trip NOLA website

Static, responsive HTML/CSS/JS build based on the approved bright editorial watercolor direction.

## Included
- Animated/flickering “NEW ORLEANS IS CALLING” marquee lettering
- Circular guide navigation
- Maison St. LaFleur stay feature + website + Matterport tour
- Restaurant, brunch, cocktail, nightlife/music, neighborhood and experience recommendations
- 72-hour itinerary
- “Things we'd avoid” local notes
- Cheeky New Orleans ad-libs used sparingly
- Separate custom merchandise shop page + starter custom-order form
- Responsive mobile layouts

## Deploy
Upload the contents of this folder to GitHub and connect the repository to Vercel, or deploy the folder directly on any static host.

## Merch integration
The custom-order form is currently front-end only. It can later be connected to Shopify, Printful, Printify, Etsy or another fulfillment/order backend.
